# uCity

## داستان

uCity یک بازی ساخت شهر برای کنسول Game Boy Color است.
شما نقش شهردار را دارید و باید شهر خود را بسازید و مدیریت کنید.
بازی شامل ساختمان‌ها، جاده‌ها و امکانات مختلف شهری است.

## تاریخچه

بازی در سال‌های ۲۰۱۷ تا ۲۰۱۸ توسط AntonioND/SkyLyrac ساخته شد.
این بازی از قابلیت‌های Game Boy Color استفاده می‌کند.
کد منبع بازی آزادانه در GitHub در دسترس است.

## گیم‌پلی

- ساخت ساختمان‌های مختلف شهری
- ساخت جاده و زیرساخت
- مدیریت منابع و بودجه شهر
- پاسخگویی به نیازهای شهروندان

## راهنمای کنترل

- دکمه‌های جهت‌دار: حرکت در نقشه شهر
- دکمه A: ساخت یا انتخاب
- دکمه B: حذف یا لغو
- دکمه Start: منوی اصلی
