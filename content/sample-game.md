# Sample Game

## داستان

این بازی نمونه اولیه برای بررسی چیدمان موزه است.
سازنده بازی را در سال نمونه منتشر کرده است.
داستان بازی درباره ماجراجویی کوتاه در جهان پیکسلی است.

## تاریخچه

بازی‌های خانگی دهه نود روی سخت‌افزار محدود خلاقیت زیادی نشان دادند.
این اثر نمونه خوبی از سبک پلتفرم‌سازی آن دوران است.

## راهنمای کنترل

کلید جهت‌دار برای حرکت. کلید پرش برای پریدن. کلید توقف برای مکث بازی.

## منبع و مجوز

منبع اصلی بازی سایت سازنده است.
نوع مجوز بازی مجوز آزاد عمومی است.
پیش از انتشار نهایی مدرک مجوز باید ثبت شود.
