# Geometrix

## داستان

Geometrix یک بازی پازل ساده و اعتیادآور برای کنسول Game Boy است.
هدف بازیکن ساخت ردیف یا ستون از سه فرم هندسی یکسان است.
هر ردیف یا ستون سه‌تایی ۱ امتیاز ارزش دارد.

## تاریخچه

بازی در سال ۲۰۱۵ توسط AntonioND/SkyLyrac ساخته شد.
این بازی برای کنسول‌های Game Boy و Game Boy Color طراحی شده است.
کد منبع بازی آزادانه در GitHub در دسترس است.

## گیم‌پلی

بازی سه حالت مختلف دارد:

- حذف همه: حذف تمام فرم‌های هندسی از صفحه
- محدودیت تعویض: کسب امتیاز تا پایان شمارنده تعویض
- محدودیت زمان: کسب امتیاز تا پایان زمان

ترکیب‌های متوالی امتیاز بیشتری دارند و شمارنده ترکیب تا ۹ می‌رسد.

## راهنمای کنترل

- دکمه‌های جهت‌دار: حرکت مکان‌نما
- دکمه A: تعویض فرم‌ها
- دکمه B: چرخاندن مکان‌نما
- دکمه Start: توقف بازی
