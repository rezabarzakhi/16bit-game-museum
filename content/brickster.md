# Brickster

## داستان

Brickster یک بازی پازل آجری کلاسیک برای Game Boy Color است.
آجرها را با اتصال کنار هم ویران کنید.
هر مرحله چیدمان جدیدی را پیش روی شما قرار می‌دهد.

## تاریخچه

این بازی توسط Stéphane Hockenhull (rv6502) ساخته شده است.
در سال ۱۹۹۹ برای Game Boy Color منتشر شد.
بازی از گیم‌بوی به عنوان سکوی اصلی استفاده می‌کند.

## راهنمای کنترل

- دکمه‌های جهت‌دار: حرکت
- دکمه A: انتخاب آجر
- دکمه Start: شروع بازی

## مجوز و حقوق

سازنده این بازی توزیع رایگان آن را به صورت رسمی تأیید کرده است.
امکان دانلود، کپی، توزیع و بازی با آن وجود دارد.
